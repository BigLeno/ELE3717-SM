# 🤖 ELE3717-SM - Sistemas Microcontrolados

Bem-vindos ao laboratório digital onde os microcontroladores ganham vida! 🚀

Este repositório é o lar dos códigos desenvolvidos na disciplina **Sistemas Microcontrolados (ELE3717)** do DCA. Aqui você encontrará uma jornada evolutiva do mundo dos micros, desde os primeiros passos em Assembly até projetos mais complexos em C.

## 🎯 O que você vai encontrar aqui?

### 📚 **Atividades 01-03: Os Primórdios em Assembly**

- **Stack**: AVR Assembly para ATmega328P
- **O que faz**: Controle de displays de 7 segmentos, manipulação direta de registradores
- **Nível de diversão**: 🔥🔥 (Hardcore mode ativado!)
- **Aprendizado**: Como fazer um microcontrolador "falar" na língua mais básica possível

### 🌉 **Atividade 04: A Grande Transição**

- **Stack**: C para ATmega328P
- **O que faz**: Interface com LCD, sistema de botões com auto-repeat
- **Nível de diversão**: 🔥🔥🔥 (Finalmente podemos usar `if`!)
- **Aprendizado**: A ponte entre Assembly e C - quando a vida fica mais fácil

### 🐍 **Atividade 05: Game Over? Not Today!**

- **Stack**: C modularizado, SPI, ADC
- **O que faz**: **Jogo da Cobrinha** em matriz de LEDs 8x8 com MAX7219
- **Componentes**: LCD, potenciômetro para controle, SPI para comunicação
- **Nível de diversão**: 🔥🔥🔥🔥🔥 (ÉPICO!)
- **Aprendizado**: Arquitetura modular, protocolos de comunicação, controle analógico

### 🎛️ **Atividade 06: O Filtro Mágico**

- **Stack**: C avançado, processamento digital de sinais
- **O que faz**: Filtro FIR (Finite Impulse Response) em tempo real
- **Funcionalidades**:
  - Leitura ADC de sinais analógicos
  - Processamento com filtro digital
  - Interface de usuário com LCD e botões
  - Máquina de estados para controle
- **Nível de diversão**: 🔥🔥🔥🔥 (Matemática + código = ❤️)
- **Aprendizado**: DSP em microcontroladores, sistemas em tempo real

### 🔮 **Atividade 07: Em Desenvolvimento**

- **Status**: 🚧 Em construção...
- **Expectativa**: Mais aventuras microcontroladas por vir!

## 🛠️ Tecnologias e Ferramentas

- **Microcontrolador**: ATmega328P (o coração do Arduino Uno)
- **IDEs**: Atmel Studio, VS Code
- **Linguagens**: Assembly AVR, C
- **Protocolos**: SPI, ADC, GPIO
- **Componentes**: Displays 7-seg, LCD, LEDs, botões, potenciômetros, MAX7219
